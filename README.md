# Documentation française de PHP

[![Structure](https://github.com/php/doc-fr/actions/workflows/build.yml/badge.svg)](https://github.com/php/doc-fr/actions/workflows/build.yml)
[![Style](https://github.com/php/doc-fr/actions/workflows/check-style.yml/badge.svg)](https://github.com/php/doc-fr/actions/workflows/check-style.yml)

Ce dépôt contient la traduction française du manuel de PHP.

Pour **lire** la documentation, aller sur php.net :
https://www.php.net/manual/fr/

Pour **contribuer** à la traduction, lire le guide du contributeur :
[CONTRIBUTING.md](CONTRIBUTING.md). La terminologie et les règles de style
imposées sont dans [TRADUCTIONS.txt](TRADUCTIONS.txt).

Si une erreur est présente dans la documentation, vérifier d'abord qu'elle ne se
trouve pas aussi dans la documentation anglaise : dans ce cas, c'est
[php/doc-en](https://github.com/php/doc-en) qu'il faut corriger, la traduction
française suivra.

## État de la traduction

- Synthèse : https://doc.php.net/revcheck.php?p=filesummary&lang=fr
- Fichiers à mettre à jour : https://doc.php.net/revcheck.php?p=files&lang=fr
