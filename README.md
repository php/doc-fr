Ce dépôt contient la traduction française du manuel de PHP, publiée sur
[php.net](https://www.php.net/manual/fr/).

Contribuer
----------

Les contributions sont les bienvenues. Le guide du contributeur est dans
[CONTRIBUTING.md](.github/CONTRIBUTING.md). La terminologie et les règles de style
imposées sont dans [TRADUCTIONS.txt](TRADUCTIONS.txt).

> [!NOTE]
> Si une erreur est présente dans la documentation, vérifier d'abord qu'elle ne
> se trouve pas aussi dans la documentation anglaise. Dans ce cas, c'est
> [php/doc-en](https://github.com/php/doc-en) qu'il faut corriger, la traduction
> française suivra.
